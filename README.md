Springboard App Privacy Policies

This repository hosts the privacy policies for applications developed or maintained by Springboard.

The policies are published using GitHub Pages and are publicly accessible for users and app store compliance.

Maintenance

Each application has its own Markdown file containing its privacy policy. Updates are published automatically through GitHub Pages.

Privacy policies must reflect the actual data processing practices of the respective application. Changes should be reviewed with the responsible organization before publication.
